5. 评委追问包

Q：市场规模是怎么算的？会不会拍脑袋？
路径透明：人口→家庭→年支出→可触达占比→地理可服务→三年份额。当前 TAM 1071.69 亿，SAM 45.01 亿，SOM 1.01 亿。每一层假设都在 config 里，评委改渗透率可即时重算。
Q：和现有玩家比，差异化是什么？
苏里优选 定位新鲜度与私域复购，不和「城南大卖场」拼绝对低价。今日告警 3 条，优先处理 P1（份额/价格），避免全面促销战。
Q：单位经济能不能打平？
客单 68 元、毛利 28%、履约 9.5 元、单均贡献 7.5 元、CAC 22 元，回本约 0.9 个月。健康（回本上限 18 个月）。
Q：悲观情景下还成立吗？
三情景已跑：悲观需求×0.75、CAC×1.25、毛利下调。悲观 SOM 0.50 亿、回本 5.1月；基准 SOM 1.01 亿、回本 0.9月；乐观 SOM 1.51 亿、回本 0.4月。若悲观回本超上限，应收缩地理而非加大补贴。
Q：为什么选苏州而不是先做全国？
先吃透可服务地理（演示设为人口 28% 核心区），把履约半径和复购跑通，再用 SOM 份额目标检验密度，而不是全国铺开烧 CAC。
Q：预算加 20% 应该投在哪？
优先投能拉高月复购与贡献的动作（会员、履约时效），而不是无差别补贴；若竞品价格战告警为 P1，只跟核心 SKU。
