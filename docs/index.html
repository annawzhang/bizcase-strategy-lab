0. 商赛简介 · 架构与贡献

全国高校商业精英挑战赛由中国贸促会商业行业委员会等牵头主办，本仓对齐「品牌策划赛道」方法：企业出题—院校答题—行业判卷；真实品牌须企业书面授权。团队通常 3–5 名选手 + 1–2 名指导教师。

真实履历：宋锦品牌（真实参赛） · 全国三等奖 · 角色 数据分析与量化建模
本仓演示：苏里优选 · 苏州社区零售（本仓虚构演示） · 平台 https://ssyth.cubec.org.cn/

SOP 赛程（品牌策划赛道）

知识赛→校赛→省赛 / 全国预选赛→全国总决赛→精英赛 / 全球赛
阶段要求（公开细则摘要）
知识赛品牌基础理论在线测评，满 100、≥60 分获组队资格
校赛院校自组织选拔；推选比例有上限后晋级
省赛 / 全国预选赛评审策划书（预选）或策划书 + 答辩（省赛）
全国总决赛策划书 + 视频展示 + 实时答辩；评全国一/二/三等奖
精英赛 / 全球赛优秀队晋级路演或全球青年商业挑战赛选拔

5. 波特五力 · 苏州社区零售

五力均强约 3.6/5；当前最紧的是「现有竞争者竞争程度」（强）。苏州社区零售里，宜用履约密度与私域复购对冲价格战，而不是全面降价。

力强度刻度驱动因素对我方含义

新进入者威胁3/5 · 中●●●○○社区团购/前置仓进入门槛中等；履约站与地推仍需资本与密度用可服务地理密度与会员复购抬高进入成本
替代品威胁4/5 · 强●●●●○大卖场到店、外卖即时零售、超市 Mini 店均可替代「社区订购」强调 2 小时履约与生鲜品质，弱化纯比价心智
